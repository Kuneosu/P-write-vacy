# P-write-vacy (React)

프라이버시를 보호하는 텍스트 에디터 - 옆에서 보는 사람으로부터 글을 보호합니다.

## 주요 기능

- **중심시야 최적화**: 커서 주변만 선명하게 표시하고 나머지는 블러 처리
- **실시간 포커스 추적**: 텍스트 입력 시 커서를 자동으로 따라가는 타원형 포커스
- **커스터마이징 가능한 설정**:
  - 포커스 영역 크기 조절 (가로/세로)
  - 블러 영역 색상 및 투명도 설정
- **키보드 단축키**: Ctrl+H로 빠른 프라이버시 모드 토글
- **자동 저장**: 로컬스토리지에 자동으로 내용 저장

## 기술 스택

- React 18 + TypeScript
- Vite (빌드 도구)
- TailwindCSS (스타일링)
- 순수 브라우저 API (Selection API, ContentEditable)

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 사용 방법

1. 텍스트 에디터에 글을 입력하세요
2. 커서 주변만 선명하게 표시되어 옆에서 보기 어렵습니다
3. 우측 상단의 설정 버튼(⚙️)을 클릭하여 세부 설정 조정
4. Ctrl+H로 프라이버시 모드를 켜고 끌 수 있습니다

## 키보드 단축키

- `Ctrl + H`: 프라이버시 모드 토글
