# P-write-vacy 사용자 가이드

## 첫 실행

### 온보딩 화면

앱을 처음 실행하면 4페이지로 구성된 온보딩 화면이 나타납니다:

1. **Welcome 페이지**: P-write-vacy 소개 및 주요 개념 설명
2. **Privacy Mode 페이지**: 프라이버시 모드 작동 방식 시연
3. **Markdown Viewer 페이지**: 마크다운 편집/미리보기 기능 소개
4. **Presets 페이지**: 프리셋 저장 및 전환 기능 소개

#### 온보딩 네비게이션
- **다음/이전**: 화살표 키 (`←` / `→`) 또는 화면 하단 버튼 클릭
- **페이지 이동**: 하단 인디케이터 점 클릭
- **시작하기**: 마지막 페이지에서 `Enter` 또는 "시작하기" 버튼
- **건너뛰기**: 언제든 `Escape` 키

### 폴더 선택

온보딩을 완료하면 폴더 선택 화면이 표시됩니다:

1. "폴더 선택하기" 버튼 클릭
2. 작업할 폴더 선택
3. 선택한 폴더의 파일 트리가 좌측에 표시됩니다

## 기본 기능

### 텍스트 편집

- 에디터 영역을 클릭하여 글 작성 시작
- 텍스트 입력 시 커서 주변만 선명하게 표시됩니다
- 파일은 수정 후 1초 후 자동으로 저장됩니다

### 파일 열기

1. `Ctrl+S`로 파일 탐색기 열기
2. 파일 트리에서 원하는 파일 클릭
3. 에디터에 파일 내용이 표시됩니다

### 저장 상태 확인

- 우측 상단에 저장 상태 표시
- "저장 중" → "저장됨" 순서로 표시
- 오류 발생 시 "저장 실패" 메시지

## 프라이버시 모드

### 프라이버시 모드란?

커서/마우스 주변만 선명하게 표시하고 나머지 영역은 블러 처리하여, 옆에서 보는 사람으로부터 글을 보호합니다.

### 켜고 끄기

- **키보드**: `Ctrl+H`
- **마우스**: 우측 상단 눈 아이콘 클릭
- **설정 패널**: 프라이버시 모드 토글 스위치

### 포커스 영역 조절

설정 패널(⚙️)에서 다음을 조절할 수 있습니다:

#### 모양
- **타원형**: 가로/세로 크기를 다르게 설정 가능
- **원형**: 동일한 크기의 원형 포커스

#### 크기
- **가로 크기**: 30px ~ 150px
- **세로 크기**: 15px ~ 100px (타원형일 때만)
- 원형일 경우 크기 슬라이더 하나로 조절

#### 블러 영역
- **블러 색상**: 색상 선택기로 원하는 색 선택
- **투명도**: 0% ~ 100%
- **블러 강도**: 0px ~ 20px
- **테두리 번짐**: 0 ~ 100 (포커스 영역 가장자리 번지는 정도)

#### 에디터 스타일
- **배경 색상**: 에디터 배경색 변경
- **텍스트 색상**: 텍스트 색상 변경

## 파일 관리

### 파일 탐색기 열기/닫기

- `Ctrl+S`: 파일 탐색기 토글
- 파일 탐색기 상단 X 버튼 클릭

### 새 파일/폴더 만들기

1. 파일 탐색기 상단 도구 모음에서 버튼 클릭:
   - **📄**: 새 파일
   - **📁**: 새 폴더
2. 파일/폴더 이름 입력
3. `Enter` 또는 체크 버튼으로 생성
4. `Escape` 또는 X 버튼으로 취소

### 파일 정렬

정렬 버튼(⬍)을 클릭하여 정렬 기준 변경:
- 이름 (A-Z / Z-A)
- 수정일 (최신순 / 오래된 순)
- 생성일 (최신순 / 오래된 순)

### 폴더 펼치기/접기

- **모두 펼치기**: 파일 탐색기 상단 펼치기 버튼
- **모두 접기**: 파일 탐색기 상단 접기 버튼
- **개별 폴더**: 폴더명 옆 화살표 아이콘 클릭

### 파일/폴더 조작

파일이나 폴더에서 마우스 우클릭하여 컨텍스트 메뉴 열기:
- **이름 변경**: 파일/폴더 이름 변경
- **복제**: 파일/폴더 복사본 생성
- **삭제**: 파일/폴더 삭제 (확인 필요)
- **기본 앱에서 열기**: 시스템 기본 앱으로 열기
- **Finder에서 보기**: Finder에서 위치 표시
- **경로 복사**: 파일/폴더 전체 경로 복사

### 드래그 앤 드롭

- 파일/폴더를 다른 폴더로 드래그하여 이동
- 드롭 영역이 강조 표시됩니다
- 하위 폴더로는 이동할 수 없습니다

### 다중 선택

1. `Ctrl` 또는 `Cmd` 키를 누른 상태로 여러 파일/폴더 클릭
2. 선택된 항목이 강조 표시됩니다
3. 우클릭으로 일괄 작업:
   - **모두 복제**: 선택한 모든 항목 복제
   - **모두 삭제**: 선택한 모든 항목 삭제

## 마크다운 뷰어

### 마크다운 파일 열기

마크다운 파일(.md)을 선택하면:
- 우측 상단에 뷰어 토글 버튼 표시
- 기본적으로 편집 모드로 시작

### 뷰어 모드 전환

- 우측 상단 눈 아이콘 버튼 클릭
- 편집 모드 ↔ 미리보기 모드

### 지원되는 마크다운 문법

- 제목 (# ~ ######)
- 굵게 (**텍스트**), 기울임 (*텍스트*)
- 목록 (-, *, 1.)
- 링크 ([텍스트](URL))
- 이미지 (![alt](src))
- 코드 블록 (```)
- 인용 (>)
- 테이블
- 체크박스 (- [ ] / - [x])

### 이미지 로딩

- 마크다운의 이미지는 지연 로딩됩니다
- 스크롤 시 보이는 이미지만 로드하여 성능 최적화

## 설정 및 프리셋

### 설정 패널 열기

- 우측 상단 ⚙️ 버튼 클릭
- `Escape` 키로 닫기

### 프리셋 기능

자주 사용하는 포커스 설정을 프리셋으로 저장할 수 있습니다.

#### 프리셋 저장
1. 원하는 포커스 설정 조절
2. 설정 패널 상단 "현재 설정 저장" 버튼 클릭
3. 프리셋 이름 입력
4. 체크 버튼으로 저장 (최대 3개)

#### 프리셋 적용
- 저장된 프리셋 클릭
- 설정이 즉시 적용됩니다

#### 프리셋 관리
- **마우스 오버**: 프리셋 세부 정보 확인
- **우클릭 → 이름 변경**: 프리셋 이름 수정
- **우클릭 → 삭제**: 프리셋 삭제

### 언어 변경

1. 설정 패널 하단 "언어" 섹션
2. 한국어 또는 English 버튼 클릭
3. 즉시 선택한 언어로 전환

## 문제 해결

### 온보딩이 다시 나타나지 않아요

온보딩을 다시 보려면:
1. 브라우저 개발자 도구 열기 (`F12`)
2. Application 탭 → Local Storage
3. `p-write-vacy-onboarding-completed` 키 삭제
4. 페이지 새로고침

### 파일이 저장되지 않아요

1. 파일 시스템 권한 확인
2. 디스크 공간 확인
3. 파일명에 특수문자가 없는지 확인
4. 브라우저 콘솔에서 에러 메시지 확인

### 프라이버시 모드가 작동하지 않아요

1. 프라이버시 모드가 켜져 있는지 확인 (`Ctrl+H`)
2. 포커스 영역 크기가 너무 작지 않은지 확인
3. 브라우저가 최신 버전인지 확인

### 파일 탐색기가 열리지 않아요

1. `Ctrl+S`로 다시 시도
2. 폴더를 다시 선택해보세요
3. 페이지를 새로고침하세요

### 마크다운 뷰어에 이미지가 표시되지 않아요

1. 이미지 경로가 올바른지 확인 (상대 경로 또는 절대 경로)
2. 이미지 파일이 존재하는지 확인
3. 이미지 형식이 지원되는지 확인 (jpg, png, gif, svg, webp)

### 언어가 변경되지 않아요

1. 설정 패널에서 다시 언어 버튼 클릭
2. 페이지 새로고침
3. localStorage가 차단되지 않았는지 확인

### 성능이 느려요

1. 파일 탐색기에 너무 많은 파일이 있는지 확인 (>1000개)
2. 마크다운 파일에 너무 큰 이미지가 있는지 확인
3. 브라우저 확장 프로그램 비활성화 시도
4. 브라우저 캐시 정리
