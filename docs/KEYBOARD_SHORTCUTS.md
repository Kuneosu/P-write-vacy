## 전역 단축키

애플리케이션 어디서나 사용 가능한 단축키입니다.

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Ctrl + S` | 파일 탐색기 토글 | 파일 탐색기를 열거나 닫습니다 |
| `Ctrl + H` | 프라이버시 모드 토글 | 프라이버시 모드를 켜거나 끕니다 |

> **참고**: macOS에서는 `Ctrl` 대신 `Cmd`를 사용할 수 있습니다.

## 온보딩 화면

첫 실행 시 나타나는 온보딩 화면에서 사용 가능한 단축키입니다.

### 네비게이션

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Arrow Right` 또는 `→` | 다음 페이지 | 다음 온보딩 페이지로 이동 |
| `Arrow Left` 또는 `←` | 이전 페이지 | 이전 온보딩 페이지로 이동 |
| `Enter` | 시작하기 | 마지막 페이지에서 온보딩 완료 |
| `Escape` | 건너뛰기 | 언제든 온보딩 종료 |

### 추가 기능

- 화면 하단의 페이지 인디케이터를 클릭하여 특정 페이지로 바로 이동 가능
- 현재 페이지는 더 크고 어두운 점으로 표시
- 화살표 키로 빠르게 모든 페이지 탐색 가능

## 파일 탐색기

파일 탐색기가 열려 있을 때 사용 가능한 단축키입니다.

### 기본 조작

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Ctrl + S` | 파일 탐색기 토글 | 파일 탐색기를 열거나 닫습니다 |
| `Escape` | 파일 탐색기 닫기 | 파일 탐색기 패널만 닫기 |
| `Tab` | 다음 요소로 포커스 | 포커스를 다음 클릭 가능한 요소로 이동 |
| `Shift + Tab` | 이전 요소로 포커스 | 포커스를 이전 클릭 가능한 요소로 이동 |

### 파일 선택

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Ctrl + Click` (macOS: `Cmd + Click`) | 다중 선택 | 여러 파일/폴더를 선택 |
| `Click` | 단일 선택 | 파일/폴더 하나만 선택 |
| 마우스 우클릭 | 컨텍스트 메뉴 | 파일 조작 메뉴 표시 |

### 파일 입력 필드

새 파일/폴더 생성 또는 이름 변경 시:

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Enter` | 확인 | 입력 완료 및 파일/폴더 생성 또는 이름 변경 |
| `Escape` | 취소 | 입력 취소 및 필드 닫기 |

### 포커스 트랩

파일 탐색기가 열려 있을 때 포커스는 탐색기 내부에만 머뭅니다:
- 첫 번째 요소에서 `Shift + Tab` → 마지막 요소로 이동
- 마지막 요소에서 `Tab` → 첫 번째 요소로 이동
- `Escape`로 탐색기를 닫으면 포커스가 메인 영역으로 돌아감

## 설정 패널

설정 패널(⚙️)이 열려 있을 때 사용 가능한 단축키입니다.

### 기본 조작

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Escape` | 설정 패널 닫기 | 설정 패널을 닫고 메인 화면으로 돌아가기 |
| `Tab` | 다음 컨트롤로 이동 | 다음 설정 컨트롤로 포커스 이동 |
| `Shift + Tab` | 이전 컨트롤로 이동 | 이전 설정 컨트롤로 포커스 이동 |

### 설정 조절

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Arrow Left/Right` | 슬라이더 조절 | 슬라이더 값을 좌우로 조절 |
| `Arrow Up/Down` | 슬라이더 조절 | 슬라이더 값을 상하로 조절 |
| `Space` | 토글 스위치 | 프라이버시 모드 등 토글 스위치 켜기/끄기 |
| `Enter` | 버튼 클릭 | 포커스된 버튼 활성화 |

## 프리셋 관리

### 프리셋 저장

| 단축키 | 기능 | 설명 |
|--------|------|------|
| "현재 설정 저장" 버튼 클릭 | 프리셋 입력 필드 표시 | 새 프리셋 이름 입력 시작 |
| `Enter` | 프리셋 저장 | 입력한 이름으로 프리셋 저장 |
| `Escape` | 취소 | 프리셋 저장 취소 |

| 단축키 | 기능 | 설명 |
|--------|------|------|
| 프리셋 우클릭 → "이름 변경" | 이름 변경 모드 | 프리셋 이름 수정 시작 |
| `Enter` | 변경 완료 | 수정한 이름 저장 |
| `Escape` | 취소 | 이름 변경 취소 |

## 컨텍스트 메뉴

파일/폴더에서 마우스 우클릭으로 열리는 메뉴입니다.

### 단일 선택 시

| 메뉴 항목 | 단축키 | 설명 |
|-----------|--------|------|
| 이름 변경 | 클릭 | 파일/폴더 이름 변경 모드 |
| 복제 | 클릭 | 파일/폴더 복사본 생성 |
| 삭제 | 클릭 | 파일/폴더 삭제 (확인 필요) |
| 기본 앱에서 열기 | 클릭 | 시스템 기본 앱으로 열기 |
| Finder에서 보기 | 클릭 | Finder에서 위치 표시 |
| 경로 복사 | 클릭 | 파일/폴더 전체 경로 클립보드에 복사 |

### 다중 선택 시

| 메뉴 항목 | 단축키 | 설명 |
|-----------|--------|------|
| 모두 복제 | 클릭 | 선택한 모든 항목 복제 |
| 모두 삭제 | 클릭 | 선택한 모든 항목 삭제 |

### 컨텍스트 메뉴 닫기

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Escape` | 메뉴 닫기 | 컨텍스트 메뉴를 닫고 파일 탐색기로 돌아가기 |
| 메뉴 외부 클릭 | 메뉴 닫기 | 메뉴 밖을 클릭하여 닫기 |

## macOS vs Windows

일부 단축키는 운영체제에 따라 다릅니다:

| 기능 | Windows/Linux | macOS |
|------|---------------|-------|
| 파일 탐색기 토글 | `Ctrl + S` | `Cmd + S` 또는 `Ctrl + S` |
| 프라이버시 모드 토글 | `Ctrl + H` | `Cmd + H` 또는 `Ctrl + H` |
| 다중 선택 | `Ctrl + Click` | `Cmd + Click` |

> **참고**: macOS에서는 대부분의 경우 `Cmd` 키를 사용하지만, `Ctrl` 키도 지원됩니다.

## 접근성 기능

### 포커스 가시성

- 모든 인터랙티브 요소는 키보드 포커스 시 명확한 시각적 표시 제공
- 포커스 링(Focus Ring)으로 현재 포커스된 요소 확인 가능

### 스크린 리더 지원

- 모든 버튼과 컨트롤에 `aria-label` 제공
- 시맨틱 HTML 사용으로 스크린 리더 호환성 보장
- 설정 패널의 슬라이더는 `aria-valuemin`, `aria-valuemax`, `aria-valuenow` 제공

### 키보드 탐색 최적화

- 논리적인 Tab 순서
- 포커스 트랩으로 모달/패널 내부 탐색 편의성 향상
- `Escape` 키로 일관된 닫기 동작

## 단축키 충돌 방지

### 브라우저 기본 단축키 재정의

P-write-vacy는 다음 브라우저 기본 단축키를 재정의합니다:

- `Ctrl + S`: 페이지 저장 → 파일 탐색기 토글
- `Ctrl + H`: 방문 기록 → 프라이버시 모드 토글

### Electron 앱에서의 동작

Electron 데스크톱 앱에서는:
- 브라우저 단축키 충돌 없음
- 네이티브 메뉴바에서 단축키 확인 가능
- 시스템 단축키와의 충돌 최소화

## 단축키 팁

### 효율적인 작업 흐름

1. **빠른 파일 전환**: `Ctrl + S` → 파일 선택 → `Enter`
2. **프라이버시 모드 활용**: 민감한 내용 작성 시 `Ctrl + H`로 즉시 켜기
3. **프리셋 활용**: 자주 사용하는 설정을 프리셋으로 저장하여 빠른 전환
4. **키보드만으로 탐색**: Tab과 화살표 키로 마우스 없이 전체 앱 조작 가능

### 자주 사용하는 조합

- **새 파일 만들기**: `Ctrl + S` → 📄 버튼 → 이름 입력 → `Enter`
- **프리셋 저장**: ⚙️ → 설정 조절 → "현재 설정 저장" → 이름 입력 → `Enter`
- **파일 삭제**: 파일 우클릭 → 삭제 → `Enter`

## 문제 해결

### 단축키가 작동하지 않을 때

1. **브라우저 확장 프로그램 확인**: 일부 확장 프로그램이 단축키를 가로챌 수 있습니다
2. **다른 앱의 전역 단축키 확인**: 시스템 전역 단축키와 충돌하는지 확인
3. **포커스 확인**: 올바른 요소에 포커스가 있는지 확인
4. **페이지 새로고침**: 문제가 지속되면 페이지를 새로고침

### macOS에서 Cmd 키가 작동하지 않을 때

- `Ctrl` 키를 대신 사용해보세요
- Electron 앱에서는 메뉴바의 단축키 표시 확인
